# FootMate | 제휴·인수 후보 평가

- 기준일: 2026-11-16
- 목적: 운영자 제휴, 전략적 지분투자, 인수 가능성을 **하나의 평가 절차**로 비교하되, 현재 확인 가능한 후보는 공개자료 기반 **조사 대상**으로만 분류한다.
- 연결: [GTM 전략](P0-GTM-ENTRY-STRATEGY-20261116.md) · [근거 등록부](P0-EVIDENCE-REGISTER-20261116.md) · [기존 사업성 분석](IT-STRATEGY-CASE-STUDY.md)
- **중요:** 접촉·제휴 협의·계약·비밀유지계약(NDA)·실사·입찰·인수 추진은 **실제로 진행하지 않았다**. 타사 매출·기업가치·파트너 수익성과 사업주 동의는 검증되지 않았다.

## 1. 요약: '제휴 공급 확보' 우선, M&A는 실사 가능 조건 확인 전 보류

현행 FootMate의 제휴형 단위손익은 건당 공헌이익 **340원**, 5개 공급처 기준 월 완료 **626건**, 월 현금 손익 **−387,160원**의 가정이다. 이 수준에서 운영 책임·계약·실측 수요를 확보하지 않은 채 지분투자나 인수로 고정비와 위험을 늘리는 결론은 뒷받침되지 않는다. **현재 권고는 제휴 후보 사전조사 → 서면 권한·경제성 실사 → 제한 실증 → 확대·투자 재심의**다.

- **Long-list:** 공개자료로 이름·시설 또는 플랫폼 운영 기능이 확인된 조사 대상을 수집한다. 경쟁사, 시설, 공공시설 등 **후보 유형이 다르므로 동일한 투자 대상이라고 간주하지 않는다**.
- **Desk Short-list:** 초기 지역과 시설 특성이 부합하는 곳을 '운영 주체/계약 가능성 확인 요청 우선순위'로만 분류한다. 이는 승인된 제휴 후보 또는 인수 Short-list가 아니다.
- **Deep Dive:** 재무, 법률, 안전, 운영, 기술, 데이터, 시너지 검증에 필요한 자료가 확보된 경우에만 착수한다.
- **CDD/투자 제안:** 시장·고객·경쟁 실사와 회사/시설에 대한 검증된 자료를 연결한 뒤 경영진에게 진행/재검토/중단의 조건부 판단안을 제출한다. **현재 실사 완료 대상은 0건**이다.

## 4. 스크리닝·평점: 자료가 없으면 평가하지 않는다

### 4-1. 평가 대상 유형별 별도 관문

| 유형 | 선행 필수조건 | 부적합하면 |
| --- | --- | --- |
| 경기 운영자 제휴 | 영업·시설 사용권, 공개 가능한 슬롯·정원, 안전/보험·취소/환불 책임, 계약·정산 주체 | 제휴 검토 보류 |
| 상업시설 임차·운영 | 임차/전대 권한, 구장 가용성, 시설·인력 비용/손해배상, 사업 인허가 | 직접 운영 투자 보류 |
| 플랫폼 기술 제휴 | API/데이터 사용 허가, 고객·결제 정보 책임, 수수료 및 경쟁 제한, 보안/개인정보 | 기술·유통 제휴 보류 |
| 지분투자·인수 | 권리/지분 구조 확인, 실제 손익·현금흐름·부채/우발채무, 주요 계약, 법무·세무·노무·개인정보 실사 | **투자/인수 가격·승인 논의 금지** |

### 4-2. 운영자 제휴 후보용 100점 표준 평가 틀(미채점)

| 영역 | 제안 가중치 | 필수 증빙 예시 |
| --- | ---: | --- |
| 지역·슬롯/수요 적합성 | 20 | 시간대별 이용 가능 슬롯, 경기 수요·추가 충원 근거 |
| 안전·현장 운영 신뢰성 | 20 | 관리자/운영 매뉴얼, 사고·기상/취소 대응, 보험 |
| 계약 권한·정산 책임 | 20 | 사업자/시설 권한 증명, 계약서, 수수료·세금·환불 주체 |
| 단위 경제성·지속 가능성 | 20 | 서면 견적, 실제 거래·원가/관리비, 민감도 |
| IT·데이터 정합성 | 10 | 슬롯/정원 갱신 방식, 중복 방지, 개인정보 최소화 |
| 전략적 보완성/시너지 | 10 | 기존 채널과 중복 여부, 운영 개선의 실증 근거 |
| **합계** | **100** | **모든 항목 확인 후 채점** |

- **비채점 기준:** 관측·증빙이 없으면 '미확인(N/A)'으로 표시한다. 미확인을 임의 0점·중간점·가산점으로 바꾸지 않는다.
- **통과 게이트:** 계약 권한·안전/보험·수익배분·환불/개인정보에서 하나라도 중대한 미해결 문제가 있으면 합산점수와 상관없이 **보류**. 이후 실제 지표·평가자·자료일을 붙여 점수를 계산한다.
- **우선순위 결정:** 서류 검증 전에는 지리적 적합성에 따른 **조사 순서만** 정할 수 있다. '기업가치/투자 매력도 점수'로 재사용하지 않는다.

## 6. 거래 방식 비교 및 의사결정 조건

| 선택지 | 현재 전략적 평가 | 권고 |
| --- | --- | --- |
| 제휴 실증 | 원 모델의 공급 확보 가설을 작은 범위에서 검증 가능 | **조건부 우선**: 운영자 권한·계약·안전·정산을 먼저 증명 |
| 지역/채널 제휴 확대 | 실제 30일 재참가·건당 공헌이익·운영시간 증빙 필요 | 초기 실증 결과 후 심의 |
| 기술 제휴/API | 데이터 권한·결제/취소/중복 예약 책임 미검증 | 기술·계약 실사 후 판단 |

| M&A/인수 | 인수대상 특정 법인·실사·자금 조달·통합 비용 검증 없음 | **현재 보류**. 가치/가격을 임의로 쓰지 않음 |

실측 시너지가 확보되면 **인수보다 제휴가 적합한 이유**와 반대의 경우(전속 공급 통제, 내부 역량 확보, 법적·기술 통합 비용)를 비교할 수 있다. 어느 대안도 검증 전에는 우수하다고 확정하지 않는다.

## 7. 경영진 보고용 의사결정 메모(작성 양식)

- **결정 요청:** 조사/자료 요청/계약 실증/확대/지분투자/인수 중 정확히 하나
- **대상 및 권리:** 후보 ID, 법인/시설 소유자, 계약 가능자, 확인 문서·일자
- **전략 적합성:** 시장/고객·제품 포트폴리오 연계, 선택하지 않을 대안과 이유
- **사업성:** 실제 확보 슬롯·완료량·건당 공헌이익·계약 고정비·현금 소요; 원본 기준 가정과 차이
- **위험:** 안전·환불·보험·독점·규제·개인정보·통합 위험, 미해결 수준
- **판정:** 진행/조건부 진행/보류/중단, 선행 조건·책임자·재심의일·허용 예산
- **첨부:** 출처 목록, 원장·계약·질문/답변, 계산 버전, 미확인 목록

### 조사 결과 및 판단

**결론: C01·C02 운영 주체와 계약 가능성 확인을 제안하되 정식 제휴·투자·인수 Short-list는 0건.** 공공시설·경쟁 플랫폼·후속 생활권은 별도 유형으로 관리한다. 현재 공개 정보만으로 사업 가치/수익배분·실제 사업화 가능성을 정량화하지 않는다.

## 8. 출처·한계

각 후보의 출처와 해당 출처가 입증하는 **정확한 범위**는 [외부 근거 등록부](P0-EVIDENCE-REGISTER-20261116.md) 참조. 자료 확인일 2026-11-16. 외부 사이트의 게시 날짜·과거 경기 정보를 현재 실시간 운영이나 제휴·투자 의향으로 해석하지 않는다. 기존 사업성 가정과 5개년 계획은 변경하지 않는다.
