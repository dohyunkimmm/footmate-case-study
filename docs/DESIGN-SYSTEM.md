# FootMate 통합 디자인 기준 (웹 보고서 + 발표자료)

## 적용 범위
- 웹: 메인 9개 섹션, 월간 손익 계산 페이지, 의사결정 메모, 발표자료 뷰어
- 발표자료: 사업성 분석 PPTX 9장 + 중장기 경영전략 PPTX 6장
- 변경 원칙: 사업 가정·수치·손익 계산식·표의 산식·결론·출처를 시각 고도화 작업에서 변경하지 않는다.

## 디자인 토큰
| 역할 | 색상 | 사용 |
| --- | --- | --- |
| 구조·제목 | #142C39 | 네이비 사이드바, 제목, 표 헤더 |

| 결정·주요 시나리오 | #087B60 | 현재 위치, 선택안, 핵심 그래프 |
| 극소수의 브랜드 강조 | #CDF35D | 어두운 배경 위의 핵심 강조 |
| 본문 | #1B2931 | 본문 텍스트 |
| 보조 텍스트 | #52636D | 설명과 주석 |
| 배경 | #F5F7F6 | 페이지 바탕 |
| 약한 강조 | #EAF5F1 | 핵심 KPI·기준 시나리오 |

| 구분선 | #DBE5E3 | 표와 카드 구분 |

- 글꼴: Pretendard. 숫자는 tabular-nums 적용.
- 문서형 웹: 메인 제목 36px(데스크톱), 28px(모바일 기준); 본문 약 16~17px. 본문 너비는 최대 960px을 권장한다.
- 배지나 장식보다 **제목 → 결론 → 핵심 숫자 → 비교 → 근거** 순서를 우선한다.
- 차트는 녹색=선택안/긍정, 회색=비교, 적갈색=손실로 의미를 고정한다. 색상 외에 수치·레이블로 의미를 함께 전달한다.

## 웹 UI·UX
- 9개 섹션을 유지하고 목차/해시/뒤로가기/키보드 포커스를 보존한다.
- 스크롤 진행 표시를 제공하되 스크린리더 반복 안내를 만들지 않는다.
- 모바일 320px 이상, 200% 확대 시 콘텐츠가 잘리거나 수평 스크롤이 발생하지 않아야 한다.
- 핵심 카드·시나리오·손익 표는 색상과 글자 크기만으로 구별하지 않는다.
- 데이터와 인터랙티브 시뮬레이션은 기존 계산 및 입력값 검증 로직을 유지한다.

## PPT
- 사업성 분석 9장: 01 대표 판단, 02 책임, 03 전환, 04 단위 손익, 05 차이, 06 통제, 07 자원, 08 ROI, 09 투자 결론.
- 전략 6장: 01 표지, 02 공급 성장, 03 협상 효과, 04 월 경제적 손익, 05 자원관리, 06 결론.
- PPTX는 수정 가능한 원본을 유지한다. 웹에 쓰이는 PNG/JPG는 **PPTX 렌더 결과에서 재생성**한다.
- 발표 시 1장에 하나의 주요 결론을 우선 노출한다. 이미 명확한 차트는 무리하게 다른 종류로 바꾸지 않는다.
- **월 경제적 손익(기회비용 포함)**과 **연간 투자 후 현금수지(기회비용 별도)**를 동일 지표처럼 표시하지 않는다.
- 원본 15장의 텍스트 값과 개수, 핵심 시나리오 수치는 원본 그대로 보존한다.

## 검증 명령
- `python qa/unify-web-and-presentations-20261111.py`: PPTX 수정 + 15개 미리보기 재생성(렌더 도구 필요)
- `python qa/crosscheck-case-study-presentations.py`: 웹 본문·PPT 2종 숫자와 핵심 문구 대조
- `npm run test:report`: 모바일·데스크톱·200% 확대·접근성·발표자료 동작 테스트
- 자동화: GitHub Actions `FootMate Design Sync` 및 `FootMate Case Study QA`

> UI 수정을 위한 문서이며 실제 영업/재무 실적 인증을 의미하지 않는다.
